SLAM PRINCIPLES IN ECHO

1. Simulated LiDAR / Sonar Raycasting

When you press SPACE, the agent acts as an autonomous mobile robot equipped with a 2D rangefinder. The sensor casts 180 radial rays evenly spanning 360° ($\Delta\theta = 2°$). Each ray steps forward until hitting an obstacle or reaching max range ($R$).

2. Occupancy Grid Mapping

The environment is discretized into a 2D matrix where each cell $m_{(r,c)}$ maintains belief state:
• Unknown (0): Unvisited black space.
• Free (1): Passed through by ray, marked navigable.
• Occupied / Wall (2): Ray termination boundary.
The persistent faint map simulates robot memory accumulating sensor measurements over time: $P(m \mid z_{1:t}, x_{1:t})$.

3. Localization & Odometry

The player dot represents the localized state estimation $\mathbf{x}_t = [x, y]^T$ of the agent inside the global map coordinate frame.

4. Breadth-First Search (BFS) Adversarial Pathfinding

When a pulse emits sound at position $\mathbf{x}_{noise}$, the creature computes the shortest Euclidean path using BFS on the open grid graph, imitating robot motion planning toward acoustic frontiers.
