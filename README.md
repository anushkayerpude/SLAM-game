🤖 SLAM Quest

A gamified simulation of Simultaneous Localization and Mapping (SLAM).

SLAM Quest is an interactive game where players control a simulated robot, explore unknown environments, complete fun tasks, and watch the environment get mapped in real time using simulated sensor data.

🛠️ Tech Stack

* Frontend: Next.js, React, TypeScript, Three.js
* Backend: Python, FastAPI, WebSockets
* SLAM: OpenCV, NumPy, Occupancy Grid Mapping, LiDAR Simulation

🎮 Planned Features

* 🤖 Robot exploration and controls
* 📡 Simulated LiDAR
* 🗺️ Real-time SLAM mapping
* 🎯 Missions and challenges
* 🚧 Obstacles and dynamic environments
* ⭐ Scoring and achievements
* 🔄 Localization & loop-closure visualization

🚧 Status

Work in Progress

The project is actively being developed. Features, gameplay, and the SLAM implementation are being built incrementally.🚀
